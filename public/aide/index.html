PROTOCOLE D'IMPRESSION

1. Connexion Réseau

Si vous n'avez pas de connexion active, connectez-vous impérativement au Wi-Fi suivant :

> SSID : Numerilab
> PASSWORD : numerilab

2. Transfert du Fichier

Rendez-vous dans la section Dépôt Fichier de ce site web.

Déposez votre fichier au format .STL dans la zone prévue à cet effet.

3. Récupération (Sur PC Imprimante)

Allez physiquement sur le PC qui contrôle les imprimantes.

1. Cliquez sur la barre des menus (en haut à gauche).
2. Cliquez sur l'icône Dossier située dans la barre latérale de droite.

Vous devriez voir apparaître le fichier que vous venez d'uploader depuis le site.

4. Tranchage (Slicing)

Glissez-déposez (drag & drop) votre fichier dans le logiciel correspondant à la machine souhaitée :

* Cura (pour Ultimaker)
* Bambu Studio (pour Bambu Lab)

Cliquez sur le bouton Trancher (ou "Slice").

5. Envoi à l'impression

Une fois le calcul terminé, cliquez sur Envoyer vers l'imprimante.

ATTENTION CURA : Une fenêtre apparaîtra pour vous demander de choisir l'imprimante cible. Sélectionnez la bonne machine avant de valider.
