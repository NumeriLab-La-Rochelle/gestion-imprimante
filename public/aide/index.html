Procédure d’impression

1. Connexion réseau

Vérifiez que votre machine est connectée au réseau du laboratoire et que l’accès aux imprimantes est autorisé. La connexion réseau et les permissions de sécurité doivent être validées avant toute impression.

2. Déposer le fichier

Allez dans Dépôt fichiers, sélectionnez votre fichier STL et complétez les champs prénom / nom avant validation. Le fichier est ensuite stocké dans le dossier de dépôt défini par le serveur.

3. Récupérer le fichier

Sur le poste de contrôle, ouvrez le dossier de dépôt et vérifiez que le fichier est bien présent. Le nom du fichier est généré à partir des informations saisies et du nom original du modèle.

4. Tranchage

Ouvrez le fichier dans le logiciel de la machine :

  • Cura pour les Ultimaker
  • Bambu Studio pour la Bambu Lab

Vérifiez bien l’orientation, la matière, les supports et les réglages puis lancez le tranchage.

5. Envoyer et surveiller

Une fois le modèle prêt, envoyez-le vers l’imprimante et surveillez l’état depuis la page Supervision. Là, vous pouvez suivre la progression, les températures, la caméra et l’état de la machine.

Attention : ne déposer ou lancer que des fichiers autorisés et conformes aux règles du laboratoire. Les machines et les données doivent rester sécurisées.
